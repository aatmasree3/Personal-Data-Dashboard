# CSV Analysis Dashboard

The CSV Analysis Dashboard is a web application built with Next.js, Tailwind CSS, and TypeScript. It enables users to upload CSV files, perform basic data analysis, and view the results in a structured, interactive dashboard interface.

## Features

- Upload CSV files through a clean user interface
- Perform basic data analysis (such as mean, sum, count)
- View analytical results within a dedicated dashboard page
- Supports dark/light mode toggle
- Fast, responsive, and modern UI built with Tailwind CSS

## Tech Stack

| Layer        | Technologies Used                  |
|--------------|-------------------------------------|
| Frontend     | Next.js (App Router), React, TypeScript |
| Styling      | Tailwind CSS                        |
| State Management | Context API                      |
| API Routing  | Next.js Server Functions            |
| Build Tools  | pnpm, PostCSS                       |

## Getting Started
1. Clone the Repository

### Clone the repository and navigate into the project:
```bash
git clone https://github.com/your-username/Personal-Data-Dashboard.git
cd csv-analysis-dashboard
```

2. Install Dependencies
Make sure you have pnpm installed. You can also use npm.
```bash
pnpm install
```
3. Run the Development Server
```bash
pnpm dev
```
Access the app at http://localhost:3000

Usage
1. Navigate to /uploads
2. Upload a CSV file
3. Click the analyze button
4. View the results on the /dashboard page
